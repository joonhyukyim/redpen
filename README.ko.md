# Redpen

Redpen은 터미널에서 바로 문서를 읽어보고 줄 단위로 리뷰하는 Claude Code 플러그인입니다. 

- Claude의 마지막 답변이나 파일을 줄 단위로 확인합니다.
- 수정하고 싶은 줄이나 여러 줄을 범위로 지정해 코멘트를 남깁니다.
- 작성한 코멘트를 프롬프트 하나로 묶어 Claude에게 전송합니다.

## 설치

**Claude Code 세션에서 설치**

```sh
/plugin install redpen --marketplace joonhyukyim/redpen
# "Add marketplace?" 질문에 `y`로 답한 뒤 scope를 고릅니다.
```

**Shell에서 설치**

```sh
claude plugin install redpen --marketplace joonhyukyim/redpen
# scope는 `-s` 옵션으로 지정할 수 있습니다(기본값: user scope).
```

## 사용법

| 명령               | 동작                                                                               |
| ---------------- | -------------------------------------------------------------------------------- |
| `/redpen`        | Redpen 창을 연다. Claude의 마지막 답변, Claude가 마지막 대화에서 고친 파일, 코멘트가 달린 파일을 목록에서 확인할 수 있다. |
| `/redpen <path>` | 경로로 파일을 연다. 마지막 대화에서 Claude가 고친 파일이면 diff를, 아니면 파일 전체를 연다.                       |

Redpen은 열릴 때 키보드 포커스를 가져옵니다. `Esc`를 누르면 프롬프트로 돌아가고, `Ctrl+X` `Tab`을 누르면 다시 Redpen으로 포커스가 옮겨 갑니다. Redpen을 닫으려면 `Ctrl+X` `X`를 누릅니다.

### 목록 화면

목록 화면은 두 부분으로 나뉩니다.
- `최근 수정`에는 마지막 대화에서 Claude가 고친 파일이 나오고, 그 대화의 diff를 확인할 수 있습니다.
- `전송 대기`에는 코멘트가 달린 파일이 첫 코멘트를 단 순서로 나옵니다.

파일 목록은 `/clear`, `/resume`, Claude 재시작 한 뒤에는 비어있는 상태가 됩니다.

| 단축키         | 동작          |
| ----------- | ----------- |
| ↑↓, `Enter` | 항목으로 이동해 열기 |
| `1`         | 다른 파일 열기    |
| `0`         | 전송 확인 화면 열기 |

`1`(파일 열기)을 누르면 단축키 자리에 입력란이 열립니다. `/redpen <path>`와 같은 방식으로 경로를 입력하고 Enter로 파일을 선택할 수 있습니다. 비운 채 Enter를 누르면 닫히고, 파일이 아닌 경로면 열리지 않습니다. 입력란이 비어 있으면 이번 세션에서 수정한 파일들(최근 순, 앞에 `↺` 표시)이 나오고, 입력을 시작하면 디렉토리 경로 추천이 나옵니다. ↓로 후보로 이동해 Enter를 눌러 선택할 수 있습니다.

### 문서 화면

| 단축키 | 동작                                                     |
| --- | ------------------------------------------------------ |
| `1` | 목록 화면으로 돌아가기                                           |
| `2` | 변경 부분(diff)만 보기와 전체 보기를 토글                             |
| `3` | 현재 줄부터 범위 선택을 시작. Enter로 코멘트를 쓰거나, `3`을 다시 눌러 범위 선택 취소 |
| `0` | 전송 확인 화면 열기                                            |

코멘트 쓰기: `Enter`로 입력란을 열고, 다시 `Enter`로 저장합니다. 비운 채 `Enter`를 누르면 취소됩니다.

한 줄에는 코멘트를 하나만 달 수 있습니다. 범위 코멘트는 범위의 마지막 줄에 붙습니다. 이미 코멘트가 달린 줄에서 `Enter`로 수정할 수 있습니다.

diff 화면에 보이지 않는 코멘트는 `표시되지 않은 코멘트 N개` 아래에 나옵니다. 거기서 Enter를 눌러 해당 코멘트를 수정할 수 있습니다.

### 전송 화면

목록이나 문서 화면에서 `0`을 누르면 전송 확인 화면이 열립니다.

| 단축키     | 동작                                           |
| ------- | -------------------------------------------- |
| ↑↓      | 코멘트 사이를 이동                                   |
| `Enter` | 그 자리에서 코멘트를 수정                               |
| `1`     | 보내지 않고 `0`을 누른 화면으로 돌아가기                     |
| `2`     | 해당 코멘트가 달린 문서로 이동                            |
| `0`     | 모든 코멘트를 프롬프트 하나로 묶어 Claude에게 보내고 목록 화면으로 돌아감 |

전송을 확인하면 다음 프롬프트가 Claude에게 전달됩니다.

```
다음 리뷰 코멘트를 모두 반영해서 수정해줘. 코멘트가 지적한 부분 외에는 건드리지 마.

1. src/foo.ts:12-18
   > (코멘트를 단 줄, 최대 8줄)
   한 번만 쓰이는 헬퍼라 인라인으로 풀어줘.
2. src/bar.ts:40 (삭제된 줄, 변경 전 기준)
   > ...
   주석 삭제.
3. src/baz.ts (위치 불명, 원래 7행)
   > ...
   ...
```

## 한계 및 주의할 점

- Claude가 Edit, Write, NotebookEdit로 고친 파일이 목록에 나옵니다. 이번 세션에서 이미 고쳤거나 코멘트가 달린 파일은 다른 방법(Bash, MCP 도구, subagent)으로 바뀌어도 turn이 끝나면 나옵니다. 그 밖의 파일은 나오지 않으니 `1`이나 `/redpen <path>`로 엽니다.
- 4 MiB를 넘는 파일은 열 수 없습니다. 아주 큰 변경은 삭제한 줄 묶음 하나와 추가한 줄 묶음 하나로 표시됩니다.
- notebook의 diff는 `.ipynb`의 JSON 원문 그대로 보입니다.
- `Esc`는 취소가 아니라 포커스를 프롬프트로 돌려보냅니다.
- 터미널에서만 동작합니다. 모바일, VS Code 패널, `claude -p`, WSL은 지원하지 않습니다.

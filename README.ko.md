# redpen

redpen은 Claude가 바꾼 내용을 pane에서 줄 단위로 리뷰하는 Claude Code mod입니다. 한 줄이나 범위에 코멘트를 남긴 뒤, 모든 코멘트를 프롬프트 하나로 Claude에게 보냅니다.

Claude Code 2.1.287 이상이 필요합니다.

## 설치

### Marketplace에서 설치

Claude Code 세션에서 실행합니다.

```
/plugin install redpen --marketplace joonhyukyim/redpen
```

"Add marketplace?" 질문에 `y`로 답한 뒤 scope를 고릅니다.

### Shell에서 설치

```sh
claude plugin install redpen --marketplace joonhyukyim/redpen
```

user scope로 설치됩니다. 다른 scope는 `-s`로 지정합니다.

## 사용법

| 명령               | 동작                                                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `/redpen`        | Claude의 마지막 답변, Claude가 파일을 고친 가장 최근 turn의 파일, 이번 세션의 다른 파일을 목록창으로 엽니다 |
| `/redpen <path>` | 파일을 엽니다. 그 최근 turn에 Claude가 고친 파일이면 diff를, 아니면 파일 전체를 엽니다. 디렉토리는 열지 않습니다. 프롬프트 자동완성에 경로 후보가 나옵니다 |

목록은 두 부분으로 나뉩니다. `최근 수정`에는 Claude가 파일을 고친 가장 최근 turn의 파일이 나오고, 그 turn의 diff로 열립니다. 파일을 고치지 않은 turn은 이 부분을 바꾸지 않고, 중단한 turn도 포함됩니다. `파일 목록`에는 이번 세션의 다른 파일, 즉 이전 turn에서 고친 파일과 코멘트만 단 파일이 최근 순으로 나오고, 파일 전체로 열립니다. 목록은 `/clear`, resume, 재시작 뒤 비어 있는 상태로 시작합니다.

pane은 열릴 때 키보드 focus를 가져옵니다. focus가 옮겨 가지 않으면(프롬프트에 입력 중인 텍스트가 있거나, 대화상자가 열려 있거나, 다른 pane이 키를 쓰고 있을 때) `Ctrl+X` `Tab`을 누르거나, fullscreen terminal에서 pane을 클릭합니다. `Esc`를 누르면 focus가 프롬프트로 돌아가고, `Ctrl+X` `Tab`을 누르면 다시 pane으로 옮겨 갑니다. pane을 닫으려면 `Ctrl+X` `X`를 누릅니다. 다시 열 때는 `/redpen`을 입력합니다.

### 단축키

단축키 목록은 pane 맨 아래에 나옵니다(pane이 좁으면 여러 줄로 나뉩니다). 코멘트를 쓰는 동안에는 그 자리에 입력란이 나옵니다. 그 아래 줄에는 위에서 설명한 pane 키가 모든 화면과 코멘트 입력 중에 똑같이 나옵니다. 문서 화면에서는 본문과 단축키 사이에 구분선이 그어지고, pane 높이가 부족하면 구분선과 이 줄이 함께 빠집니다.

목록 화면

| 단축키     | 동작                                        |
| ------- | ----------------------------------------- |
| ↑↓, `Enter` | 항목으로 이동해 열기(Claude의 마지막 답변이 항상 첫 항목) |
| `1`     | 경로로 파일 열기(아래 참고) |
| `0`     | 코멘트 모두 보내기                                |

`1`을 누르면 단축키 자리에 경로 입력란이 열립니다. `/redpen <path>`와 같은 방식으로 경로를 입력하고 Enter를 누릅니다. 비운 채 Enter를 누르면 닫히고, 파일이 아닌 경로면 이유를 표시하고 입력란이 남습니다. 입력란 아래에는 입력한 내용에 맞는 후보가 최대 8개, 흐리게 나옵니다. 이번 세션에서 경로로 연 파일(최근 순, 앞에 `↺` 표시)이 먼저, 입력한 디렉토리에서 이어지는 항목이 그다음입니다. ↓로 후보로 이동해 Enter를 누르면 디렉토리는 입력란을 채우고, 파일은 엽니다.

문서 화면

| 키                          | 동작                                                                           |
| -------------------------- | ---------------------------------------------------------------------------- |
| `↓` / `↑`                  | ▶를 다음 / 이전 줄이나 코멘트 행으로 옮깁니다.                                                 |
| 줄에서 `Enter`, 또는 줄 번호 클릭    | 그 줄이나 범위에 코멘트를 씁니다. 이미 코멘트가 있는 줄이면 그 코멘트를 수정합니다                              |
| 코멘트 행에서 `Enter`, 또는 `└` 클릭 | 그 코멘트를 수정합니다                                                                 |

| 단축키                        | 동작                                                                           |
| -------------------------- | ---------------------------------------------------------------------------- |
| `1`                        | 목록으로 돌아가기                                                                    |
| `2`                        | diff에서 변경 부분만 보기(변경마다 앞뒤 3줄, 나머지는 `⋯`로 접음)와 파일 전체 보기를 바꿉니다. 바꾸면 범위 선택이 취소됩니다 |
| `3`                        | ▶ 줄부터 범위를 시작합니다. Enter로 코멘트를 쓰거나, `3`을 다시 눌러 취소합니다                           |
| `0`                        | 코멘트 모두 보내기                                                                   |

클릭은 터미널 창 크기와 관계없이 Claude Code의 fullscreen 화면 방식(alternate screen)에서만 동작합니다. main screen 방식(`CLAUDE_CODE_NO_FLICKER=0`, tmux의 기본값)에서는 클릭이 mod에 전달되지 않습니다.

코멘트 쓰기: Enter로 입력란을 열고, 다시 Enter로 저장합니다. 비운 채 Enter를 누르면 취소됩니다. 수정할 때는 입력란에 현재 내용이 들어 있고, 내용을 모두 지운 뒤 Enter를 누르면 코멘트가 삭제됩니다.

한 줄에는 코멘트를 하나만 달 수 있습니다. 범위 코멘트는 범위의 마지막 줄에 붙습니다. 그 줄에 이미 코멘트가 있으면 Enter로 그 코멘트를 수정합니다.

달린 줄이 화면에 보이지 않는 코멘트는 `표시되지 않은 코멘트 N개` 아래에 나옵니다. 거기서 Enter를 누르면 그 코멘트를 수정합니다.

### 보내기

`0`을 누르면 모든 코멘트를 프롬프트 하나로 묶어, 직접 입력한 것처럼 Claude에게 보냅니다.

```
다음 리뷰 코멘트를 모두 반영해서 수정해줘. 코멘트가 지적한 부분 외에는 건드리지 마.

1. src/foo.ts:12-18
   > (코멘트를 단 줄, 최대 8줄)
   한 번만 쓰이는 헬퍼라 인라인으로 풀어줘.
2. src/bar.ts:40 (삭제된 줄, 변경 전 기준)
   > ...
   주석 삭제.
3. src/baz.ts (위치 불명, 원래 7행)
   > ...
   ...
```

`삭제된 줄, 변경 전 기준`은 삭제된 줄이고, 줄 번호는 변경 전 파일 기준입니다. `위치 불명, 원래 N행`은 코멘트를 단 줄이 파일에서 사라졌고, 원래 N행에 있었다는 뜻입니다.

파일이 바뀌면 코멘트는 자신이 달린 줄의 텍스트를 따라 옮겨 갑니다. 그 텍스트가 사라지면 `위치 불명`으로 표시되고, 전송 시 함께 보내집니다.

## 보안

redpen은 목록에 있는 파일(turn이 시작하고 끝날 때, 그리고 화면에 보여 줄 때)과 Claude의 마지막 답변만 읽고, `0`을 눌렀을 때만 프롬프트를 전송합니다. 파일을 쓰거나 명령을 실행하거나 네트워크를 쓰지 않습니다. 코멘트는 세션이 끝날 때 삭제됩니다.

## 현재 버전의 한계

- Claude가 Edit, Write, NotebookEdit로 고친 파일이 목록에 나옵니다. 이미 목록에 있는 파일은 다른 방법(Bash, MCP 도구, subagent)으로 바뀌어도 turn이 끝나면 나옵니다. 그 밖의 파일은 나오지 않으니 `/redpen <path>`로 엽니다.
- turn 중에 삭제된 파일은 목록에서 빠집니다. 코멘트가 달린 파일은 남습니다.
- 한 turn에 같은 파일을 여러 번 고쳤으면 diff는 turn 전체의 변경을 보여 줍니다.
- 4 MiB를 넘는 파일은 열 수 없습니다. 아주 큰 변경은 삭제한 줄 묶음 하나와 추가한 줄 묶음 하나로 표시됩니다.
- notebook의 diff는 `.ipynb`의 JSON 원문 그대로 보입니다.
- pane 높이가 낮으면 ↑↓가 계속 동작하도록 줄과 항목 외의 행을 빼고, 긴 목록은 focus 주변 항목만 보여 줍니다. 문서 화면은 6행, 목록은 5행보다 낮으면 안내 한 줄만 나옵니다.
- `Esc`는 취소가 아니라 focus를 프롬프트로 돌려보냅니다. 범위는 `3`으로, 새 코멘트는 비운 채 Enter로 취소합니다.
- 터미널에서 동작합니다. 모바일, VS Code 패널, `claude -p`, WSL은 지원하지 않습니다. Desktop 앱에서는 테스트하지 않았습니다.
